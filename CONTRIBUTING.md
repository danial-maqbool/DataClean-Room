# Contributing

Open an issue with a small synthetic example and the expected behavior.
Run the complete test suite before submitting a change. Add a regression test for a corrected defect.
Keep processing local. Keep source files unchanged. Do not weaken input, output, consent, or encryption checks.
Use simple English in documentation. Record real interface states for screenshots.
Do not include private documents, passwords, tokens, downloaded models, or environment folders.
Describe tested platforms and skipped checks exactly. A feature is not complete because a button exists.
